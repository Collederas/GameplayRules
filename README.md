# Echo Choir

A game grown one mechanic at a time, with no plan.

Open `index.html` in a browser (sound on).

## Layers so far

1. **Echoes.** Press and drag to sing: height picks a note on a pentatonic staff. Let go and the gesture becomes an echo that loops forever, synced to a 96 BPM beat. Layer up to 10. Backspace removes the last echo, Esc clears all.
